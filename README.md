# My Vocal

ブラウザ上で動作する、サンプルベースの自作ボーカル合成アプリです。録音した音声素材を登録し、発音辞書とピアノロールを使って歌声を組み立てます。外部サーバーやAI APIは使用しません。

## 起動方法
1. このリポジトリをダウンロード、または Clone します。
2. `index.html` を Chrome / Edge / Firefox などのブラウザで開きます。
3. 「音声素材」から録音素材を登録します。
4. 「波形編集」で波形を確認し、範囲を指定してトリミング素材を作成できます。
5. 「発音辞書」で歌詞と素材を対応づけます。
6. 「ボーカル編集」でノートを追加して再生します。

## v0.2.0 の機能
- 音声素材の登録・試聴・削除
- 音声波形表示（先頭チャンネル）
- 波形クリックとスライダーによる再生位置の移動
- 選択範囲の再生と停止
- 再生位置をトリミング開始点 / 終了点に設定
- 秒単位での開始・終了位置指定
- 選択範囲を 16-bit PCM WAV として別素材に保存（元素材は保持）
- 発音辞書（文字と素材の対応づけ）
- 簡易ピアノロール、ノート編集・再生
- プロジェクト設定の JSON 書き出し / 読み込み

## データ保存
- 音声素材: IndexedDB
- ノート / 発音辞書: localStorage
- プロジェクト設定: JSON ファイルとしてバックアップ可能

ブラウザのサイトデータを消去すると保存内容が消える場合があります。録音素材と JSON バックアップは別途保管してください。

## 現在の制限
- ピッチ変更は再生速度方式のため、音高を変えると再生時間も変わります。
- ノートのドラッグ移動・リサイズ、子音＋母音の連結、時間伸縮、ビブラートは未実装です。
- 波形は先頭チャンネルを表示します。トリミング時は全チャンネルを保持します。
- 読み込める音声形式はブラウザのデコード対応形式に依存します。切り出し書き出しは WAV です。
